
Jim's Essentials
=======

[![Minecraft](https://img.shields.io/badge/Minecraft-1.21.1-cyan.svg)](https://www.minecraft.net/)
[![NeoForge](https://img.shields.io/badge/NeoForge-21.1.219+-blue.svg)](https://neoforged.net/)
![Version](https://img.shields.io/badge/Version-1.3.2-darkmagenta.svg)

>This mod is a collection of features I find necessary for a small smp server.

### So far this mod includes:

 * _[```autoshutdown```](src/main/java/com/github/jimsessentials/modules/autoshutdown): Shuts down a server when there are no players connected._
 * _[```wooltostring```](src/main/resources/data/wooltostring): Adds a crafting recipe of 4 strings from 1 wool._
 * _[```wastelands```](src/main/java/com/github/jimsessentials/dimensions/wastelands): A deserted dimension with structures, both above and below bedrock. Only portal activation can be disabled._
 * _[```nova_structures```](src/main/resources/data/nova_structures): Also known as [___Dungeons and Taverns___](https://modrinth.com/datapack/dungeons-and-taverns). Can't be disabled._
 * _[```disable_alexscaves_magnets```](src/main/java/com/github/jimsessentials/modules/disable_alexscaves_magnets): Disable all the magnetic forces defined in alexs caves mod._
 * _[```glisteringmelon```](src/main/java/com/github/jimsessentials/modules/glisteringmelon): Makes glistering melons edible._
